# Word Graph Explorer
A browser-only word ladder game for learning graph traversal. Vite, TypeScript and p5.js; no account, backend or external API. The left panel accepts valid one-letter moves and offers undo, reset, hints from the current word, and reveal from the start. The right panel draws only valid edges, marks the player route separately from the shortest route, and animates BFS with play, pause, single step, reset and speed. Show the queue, visited count, current node and search depth. Use a curated English vocabulary (not an exhaustive dictionary), three- and four-letter presets and custom endpoints. Show validation and unreachable-goal messages. Responsive stacked layout on small screens, keyboard form submission and text equivalents for canvas information.

BFS uses a FIFO queue, visits each word once, records parents and reconstructs a shortest route. The renderer never runs the search itself; snapshots keep learning state inspectable. Graph columns represent distance from the start. The complete selected connected component is shown. Tests cover adjacency, shortest routes, disconnected endpoints, normalization, invalid moves, hints and cycles. Verify TypeScript/build and browser interactions before uploading source to GitHub. Vercel deployment is a separate action; provide setup instructions.

## Interaction feedback update
Move validation also runs on input. Invalid submissions shake the field and notify; corrections dismiss stale notifications. Success animates the new ladder rung. Win state includes a persistent celebration card, a shortest-route comparison, a next-puzzle action, and temporary confetti; undo/reset clear celebration state. Graph edges animate dashes in traversal order (latest traversal for cycles), current nodes pulse, and the viewport follows the active node. Reduced-motion preferences retain text and static markings but disable motion and confetti. Browser tests exercise errors, wins, correction, undo, next challenge, mobile overflow, animated canvas and reduced-motion stability.


## Game-first learning redesign
The word ladder occupies the top of the page, with challenge selection, endpoints, legal move entry, feedback and recovery controls. Underneath, four optional tabbed experiments teach graph adjacency, FIFO search, parent reconstruction and scaling tradeoffs. Each asks for a prediction, provides specific feedback and reveals the reasoning after a correct answer. The six-word queue walkthrough uses the same pure search engine as the game but has independent state. Solution comparison uses the active puzzle and clears whenever its state changes. The full p5 graph and BFS controls live under the search lesson; the graph is loaded on demand and does not draw while hidden. Leaving that lesson pauses playback. Mobile stacks the game and experiment columns; accessible tabs support arrow keys, Home and End.
